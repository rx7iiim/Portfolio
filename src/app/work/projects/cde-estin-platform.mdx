## Overview

CDE is a comprehensive startup management platform designed for students to manage their project ideas, applications, and supervision sessions. The platform supports multiple user roles with role-based access control, allowing teachers to effectively supervise student projects.

## Key Features

- Startup and project idea management
- Supervision session tracking
- User authentication and role-based access control
- Responsive UI for students and teachers

## Technologies

- React, Next.js, Full Stack
