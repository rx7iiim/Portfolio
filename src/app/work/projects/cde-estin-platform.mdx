## Overview

The CDE ESTIN Platform is an educational/service platform for ESTIN, providing access to course materials, tools, and authenticated resources for students and staff.

## Key Features

- User authentication and role-based access
- Course and resource management
- Responsive UI for students and staff

## Technologies

- Web app deployed on Vercel with standard authentication and backend services.
