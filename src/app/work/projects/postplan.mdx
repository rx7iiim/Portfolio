## Overview

PostPlan is a content planning and social media scheduling tool that helps teams organize posts, timelines, and collaboration.

## Key Features

- Calendar-based planning
- Team collaboration and approval flows
- Scheduling to major social platforms

## Technologies

- Web app built with modern frontend frameworks and deployed on a cloud platform.
