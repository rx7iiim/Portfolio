## Overview

This project demonstrates a ratings and feedback system, allowing users to submit scores and reviews that can be aggregated and visualized.

## Key Features

- User ratings and reviews
- Aggregate scoring and visualizations
- Lightweight API for storing feedback

## Technologies

- Modern frontend with an API-backed store, deployed on Vercel.
